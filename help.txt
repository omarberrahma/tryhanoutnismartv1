# HanOuti Smart - Comprehensive Technical & Functional Guide

Welcome to the comprehensive guide for **HanOuti Smart**, a production-ready, multi-tenant POS and E-commerce SaaS. This platform is specifically customized for the Algerian market, featuring built-in Arabic RTL support, as well as French and English localization.

---

## 1. Overview
HanOuti Smart is built on a modern, highly scalable stack using **Next.js 14 (App Router)**, **Supabase** (PostgreSQL, Authentication, Row Level Security), and **Tailwind CSS**. It serves as an all-in-one platform allowing store owners to manage their inventory, conduct lightning-fast POS operations, and manage public e-commerce storefronts seamlessly. The system operates as a Progressive Web App (PWA) via `next-pwa`, enabling crucial offline capabilities.

---

## 2. Multi-tenant Architecture & Security
- **Data Isolation:** The platform utilizes Supabase Row Level Security (RLS) to enforce strict multi-tenancy. Every major entity table (e.g., `products`, `orders`, `users`) includes a `tenant_id` column. RLS policies guarantee that a tenant (store) can only query, insert, or modify data associated with their own `tenant_id`.
- **Authentication:** Powered by Supabase Auth, supporting standard Email/Password authentication and PIN-based login for POS cashiers.
- **Middleware Protection:** The `src/middleware.ts` intercepts requests. It protects `/dashboard` routes, ensuring users are authenticated, and protects `/platform` (SaaS Admin) routes, restricting access strictly to users with an "Owner" role.

## 3. Core Modules Breakdown

### Module 1: Inventory & Barcode Management
**Path:** `src/app/dashboard/inventory` & `src/app/dashboard/barcodes`
- **Inventory Tracking:** Manage products, variants, categories, stock moves (in/out/transfers), and periodic inventory counting.
- **Barcode Generator:** Specialized module (`src/app/dashboard/barcodes`) allowing store owners to design and print custom barcode labels. Supports both Thermal receipt printers (e.g., 80mm/58mm) and standard A4 printers for bulk label printing.

### Module 2: Point of Sale (POS) & Order Management
**Path:** `src/app/dashboard/pos` & `src/app/dashboard/orders`
- **Fast POS Interface:** Optimized for speed, the POS interface (`src/app/dashboard/pos`) supports barcode scanning, quick cart manipulation, and offline resilience.
- **Order Lifecycle:** The `orders` module handles the complete lifecycle from draft, pending, confirmed, to delivered. It also includes an interface for generating and printing order documents (invoices, receipts).

### Module 3: Public E-commerce Storefront
**Path:** `src/app/store/[slug]` & `src/app/store/landing/[id]`
- **Tenant Storefronts:** Each tenant gets a dedicated, SEO-friendly storefront route (`/store/their-shop-slug`) where customers can browse catalogs and place orders.
- **Landing Pages:** Support for promotional landing pages (`/store/landing/[id]`) optimized for high conversion rates.

### Module 4: Shipping & Logistics Integration
**Path:** `src/app/dashboard/shipping`
- **Shipping Providers:** Natively tailored for the Algerian market, this module allows store owners to configure and filter shipping rates using major local delivery companies:
  - **Yalidine Express**
  - **ZR Express**
  - **Maystro Delivery**
- Allows automated rate calculation based on wilaya (province) and delivery type (home delivery vs. desk pick-up).

---

## 4. Progressive Web App (PWA)
Configured using `next-pwa` in `next.config.mjs`. The platform caches core assets to ensure that critical operations, such as the POS interface, remain functional during intermittent network connectivity—a common requirement in retail environments.
